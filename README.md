# SHIFT TETRIS

画面比率と選択モードに応じて、ブロックが上下左右から進むオリジナル落ち物ゲームです。

## モード

- AUTO: スマホ縦画面は上から下、PC横画面は左から右
- DOWN: 上から下
- UP: 下から上
- RIGHT: 左から右
- LEFT: 右から左
- MIX: 5ライン消すごとに下、右、上、左へ変化

## 操作

### PC

- 矢印キー: 移動・重力方向への1マス落下
- Z / X: 回転
- Space: 即落下
- P: 一時停止

### スマホ

画面下のボタンで移動、回転、即落下できます。

## 起動

`index.html` をブラウザで開くと遊べます。

GitHub Pagesで公開する場合は、リポジトリをPublicにして、Settings → Pages → Deploy from a branch → main / root を選択してください。
