# Customer expressions

20 male customer sprite sheets, generated from each original portrait using the built-in image generation tool. Each sheet is an equal 2×2 grid: top left joy, top right anger, bottom left sadness, bottom right laughter. The original portrait remains the neutral state. Female portraits are unchanged.

Prompt: Preserve the same fictional adult customer, hairstyle, facial proportions, facial hair, glasses/hat, clothing, lighting and nightclub background. Create strongly differentiated, anatomically plausible expressions readable on a phone: bright open-eyed delighted smile; furrowed-brow angry scowl; sorrowful brows, downturned mouth and tears; eyes-closed open-mouthed laughter. No text or extra people. Output one precisely aligned 2×2 portrait sprite sheet per person.

The PNG outputs were encoded as WebP without changing the layout. The game renders the selected quadrant into the existing portrait image, retaining its contain sizing and layout. Loading failures fall back to the original portrait.
